What it does

  • Removes boilerplate, duplicates, and low-entropy content from document corpora
  • Domain-specific modules for Ansible, OpenShift must-gather, CI/CD, and systemd logs
  • Entropy pre-flight to predict impact before you build anything
  • Safety guard optimization — tiered classification eliminates most LLM guard calls
  • Zero runtime dependencies — pure Python 3.11+
