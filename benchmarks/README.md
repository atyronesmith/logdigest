# Benchmarks

Reproducible benchmarks for denoise's headline claims.

## Quick start

```bash
# Generate synthetic corpus and run all benchmarks
uv run python benchmarks/run_all.py

# Individual benchmarks
uv run python benchmarks/bench_token_savings.py
uv run python benchmarks/bench_entropy_prediction.py
```

## What these benchmarks verify

| Benchmark | Claim | Method |
|-----------|-------|--------|
| `bench_token_savings.py` | 80%+ token savings on Ansible logs | Pre-digest synthetic corpus, measure raw vs digested char/line counts |
| `bench_entropy_prediction.py` | Entropy pre-flight predicts impact | Run `corpus_entropy()` on high/low redundancy corpora, verify predictions match |

## Synthetic vs real corpus

These benchmarks use synthetic Ansible logs generated by `generate_corpus.py`. The synthetic logs match the entropy profile of real Ansible job logs (80%+ noise lines from `ok:`, `skipping:`, `changed:`, retry blocks, item loops).

The headline numbers in `docs/PREDIGESTION.md` (83.1% token savings on 500 real logs) were measured using `drift`'s experiment scripts on a corpus of real failed Ansible job logs. To reproduce those exact numbers, use:

```bash
# In the drift repo:
python scripts/predigest_corpus_stats.py --log-dir /path/to/ansible/logs -o results.json
```

The synthetic benchmarks here verify that denoise's pre-digestion machinery produces equivalent savings on structurally similar input.

## Adding a benchmark

Each benchmark is a standalone script that prints results and exits 0 on success. Add new scripts to this directory and register them in `run_all.py`.
